# AI 智能笔记 · 前端视觉与交互设计

> 版本 v1.0 · 2026-08-16
> 布局与功能对应关系见 [design.md](./design.md)

## 1. 设计定位

- **产品**：个人 AI 笔记——一个人与自己的知识库安静对话的空间。
- **受众**：产品作者本人（单用户），长时间使用不疲劳是硬指标。
- **页面唯一任务**：让「写」和「问」都自然顺手——笔记列表一键进入书写，AI 对话永远在右手边可及。
- **视觉承诺**：一套**有物理感的光的玻璃系统**。所有面板像被同一束光从上方照亮；背景极光缓慢流动；AI 的存在以青玉色呼吸光呈现，人的操作以靛蓝色呈现。写与问，在色彩上即可分辨。

## 2. 设计语言

### 2.1 色彩（命名色板）

刻意避开"AI 产品 = 蓝紫渐变"的套路组合：基底是深夜墨水蓝，主强调色用**青玉**（teal），AI 的存在感由它承担；人（用户气泡、选中态）用**靛蓝**；实体徽章是一套离散光谱，检索结果因此一眼可读。

**深色主题「夜墨」（默认）**

| 名称 | 值 | 用途 |
|---|---|---|
| `ink` | `#0B1022` | 画布基底 |
| `aurora-teal` | `#2DD4BF` | 极光光斑 ① + 主强调色 |
| `aurora-violet` | `#A78BFA` | 极光光斑 ② |
| `aurora-rose` | `#FB7185` | 极光光斑 ③（很淡，仅作暖色平衡） |
| `accent` | `#2DD4BF` | 主操作、激活态、AI 元素 |
| `accent-deep` | `#0D9488` | 强调色的深色档（实心按钮渐变尾） |
| `user-blue` | `#818CF8` | 用户气泡、用户选中态 |
| `text-1 / text-2 / text-3` | `rgba(255,255,255,.93 / .62 / .38)` | 主文字 / 次要文字 / 弱化文字 |
| `success / warning / danger` | `#34D399 / #FBBF24 / #F87171` | 状态 |

**浅色主题「晨雾」**

| 名称 | 值 |
|---|---|
| `ink` | `#EDF1F7` |
| 光斑 | 同上三色，透明度降为深色的一半 |
| `accent` | `#0D9488`，`accent-deep` `#0F766E` |
| `user-blue` | `#6366F1` |
| `text-1 / text-2 / text-3` | `rgba(15,23,42,.92 / .60 / .40)` |

### 2.2 玻璃参数

玻璃的"物理感"来自一个统一的光照模型，全部组件共用，禁止各写各的：

```css
/* 三层玻璃（由浅到深，对应层级由低到高） */
--glass-1: rgba(255,255,255,.05);   /* 面板底 */
--glass-2: rgba(255,255,255,.08);   /* 卡片 / 输入框 */
--glass-3: rgba(255,255,255,.12);   /* 悬浮层 / 激活项 */
/* 统一滤镜 */
--glass-blur: 24px;
--glass-saturate: 160%;
/* 边框与顶部受光（signature） */
--glass-border: rgba(255,255,255,.08);
--glass-border-strong: rgba(255,255,255,.18);
--glass-top-light: inset 0 1px 0 rgba(255,255,255,.10);
--shadow-glass: 0 8px 32px rgba(0,0,0,.35);
```

浅色主题下：`--glass-1/2/3` 用 `rgba(255,255,255,.50/.60/.75)`，边框用 `rgba(15,23,42,.07)`，阴影 `0 8px 24px rgba(15,23,42,.10)`。

**每个玻璃面板的完整配方**：`background + backdrop-filter(blur + saturate) + border 1px + box-shadow: --glass-top-light, --shadow-glass`。顶部那根 1px 内高光是全局签名——所有面板都"从上方被照亮"。

### 2.3 字体

不依赖外网字体（全部本地打包或系统栈）。

| 角色 | 字体 | 说明 |
|---|---|---|
| UI / 编辑器 | `Inter, -apple-system, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Noto Sans SC", sans-serif` | 系统无衬线栈 |
| **笔记预览正文** | **霞鹜文楷 LXGW WenKai**（本地打包，设置里可关） | 阅读态呈"书卷气"，与编辑态无衬线形成对照——这是本设计的排版签名 |
| 代码 / 等宽 | JetBrains Mono（本地打包），回落 `ui-monospace, Consolas` | 代码块、inline code |

字号阶：`12 / 13 / 14 / 15 / 16 / 18 / 20 / 24 / 32`。笔记标题 15px semibold；预览正文 16px / 1.85 行高；数字与日期一律 `font-variant-numeric: tabular-nums`。

### 2.4 圆角 / 阴影 / 间距 / 动效

- 圆角：面板 20px，卡片 14px，输入框/按钮 10px，chip 999px
- 间距：4px 基数，常用 8 / 12 / 16 / 24 / 32
- 动效：标准过渡 160ms `cubic-bezier(.2,.8,.2,1)`；入场 240ms；微交互 120ms
- 动效原则：**一个编排时刻**——页面载入时玻璃面板依次浮现（顶栏 → 左栏 → 列表 → AI 栏，各错开 60ms）；其余只保留 hover 微交互。散落的动画一律不要。

## 3. 布局骨架

### 3.1 画布与留白

```
┌────────────────────────────────────────────────────────────────────┐
│ 画布（100vw × 100vh，固定）                                         │
│  ├─ 背景层：ink 基底 + 三处极光光斑（blur 120px，60s 缓慢漂移）+ 细噪点 │
│  ├─ 内容容器：max-width 定宽，水平居中，左右即"两侧空白"               │
│  └─ 垂直结构：上 24px 留白 → 顶栏 60px → 12px 间隙 → 主体（剩余高度）   │
└────────────────────────────────────────────────────────────────────┘
```

| 页面 | 内容容器宽度 |
|---|---|
| 首页 | 1400px |
| 编辑页 | 1280px |
| 设置页 | 860px |
| 登录页 | 420px（卡片） |

容器小于视口时左右留白 = `(100vw - 容器宽) / 2`；视口不足时容器收缩、贴边 16px。桌面优先，最佳体验宽度 ≥ 1180px。

### 3.2 页面骨架（首页）

```
   ◄────────── 留白 ──────────► ┌────────────── 1400px ──────────────┐
                                │ ┌─ 顶栏（玻璃条 60px，圆角 20）──────┐│
                                │ │ ◈ Note · [搜索框····] [＋新增] [⚙]││
                                │ └───────────────────────────────────┘│
                                │ ↕ 12px                               │
                                │ ┌─ 主体（玻璃面板，圆角 20）──────────┐│
                                │ │┌─────┐┌───────────────┐┌────────┐││
                                │ ││分类  ││ 笔记列表       ││ AI 对话 │││
                                │ ││220px││ flex-1        ││ 380px  │││
                                │ │└─────┘└───────────────┘└────────┘││
                                │ └───────────────────────────────────┘│
                                └──────────────────────────────────────┘
```

三栏之间用 1px `--glass-border` 竖线分隔（分隔线本身也是"玻璃接缝"）。

## 4. 页面设计

### 4.1 登录页 `/login`

- 画布中央一块 420px 玻璃卡（`--glass-2`，`--glass-top-light`）
- 卡片内容自上而下：Logo（"◈ Note"，渐变字 teal→violet）→ 标题"回到你的知识库" → 用户名输入框 → 密码输入框 → 登录按钮（accent 渐变实心，全宽）
- 登录失败：卡片底部出现 danger 色提示行"用户名或密码错误"，输入框边框闪一下 danger
- 载入编排：卡片从 96% 透明度 + translateY(8px) 浮现

### 4.2 首页 `/`

**顶栏**（独立玻璃条，与主体面板之间 12px 间隙）：

- 左：Logo（渐变字）＋ 应用名
- 中：搜索框（玻璃胶囊，宽 ~360px，居中）。聚焦时边框变 `--glass-border-strong` + 外圈 teal 光晕；输入即请求笔记列表（防抖 300ms），清除按钮出现在右侧
- 右：`＋ 新增笔记`（accent 实心按钮）与 `⚙`（ghost 圆形按钮）

**左栏 · 分类导航**：

- 顶部小标题「分类」（text-3，12px，字距 +1px）
- 项目：「全部笔记」固定置顶；下面按 sort 排列各分类，右侧淡显笔记数（tabular-nums）
- 激活项：`--glass-3` 底 + 左侧 4px teal 竖条 + 文字 text-1；hover 项 `--glass-2`
- 底部「＋ 新建分类」ghost 文字按钮 → 弹出 Modal 输入名称
- 分类项右键菜单（编辑名称 / 删除）

**中栏 · 笔记列表**：

- 列表头：当前视图名（"全部笔记"/分类名）＋ 笔记总数
- 笔记卡片（`--glass-2`，圆角 14，padding 16）：
  - 第一行：标题（15px semibold，text-1）+ 右侧相对时间（text-3，12px）
  - 第二行：简介 summary 两行截断（text-2，13px）；无简介时显示正文首两行，meta 生成中显示占位骨架
  - 第三行：`#tag` 芯片组 + 实体芯片组（见 §5）
  - 右上角元数据状态点（见 §5 MetaStatusDot）
- hover：`--glass-3` 底 + 边框提亮 + `translateY(-2px)`；点击进入编辑页
- 空状态：居中虚线圆内一支笔的图标 + 「还没有笔记」+ 按钮「写第一篇」

**右栏 · AI 对话**：

- 头部：「AI 助手」标题 + 会话列表按钮（弹出会话抽屉：切换 / 删除）+「新对话」图标按钮
- 消息区：user 右侧靛蓝渐变气泡；assistant 左侧玻璃气泡（`--glass-2`），markdown 渲染；工具执行时显示状态行（§5 ToolStatusLine）
- 流式输出：光标"▍"在句尾闪烁（teal，1s 呼吸）
- 底部输入区：玻璃胶囊 textarea（自动增高，上限 6 行），Enter 发送 / Shift+Enter 换行；发送按钮圆形 accent 渐变，输入为空时禁用
- 空状态：「问我点什么」+ 三个示例问题 chip（"我上周写了什么" / "搜关于 XX 的笔记" / "总结我所有笔记的主题"）

### 4.3 笔记页 `/note/:id`（预览 / 编辑双模式）

**默认预览模式**（点击列表已有笔记进入）：顶栏静态标题 + 分类徽标 + 「编辑」按钮（accent 实心）；中间为 ByteMD Viewer 渲染区（文楷排版）；右侧写作助手保持可用（AI 修改后预览自动刷新）。

**编辑模式**（点「编辑」或新建笔记 `/note/new` 直接进入）：

**顶栏**：`←` 返回（ghost 圆形）→ 标题输入（透明底，20px semibold，placeholder"无标题"，聚焦出现底部 teal 细线）→ 分类选择器 → 「预览」（ghost，有未保存内容时先保存再切换）→「💾 保存」（accent 实心；已保存未改动时变 ghost 显示"已保存"）→ ⚙

**主体**：左/中为 ByteMD 编辑器（§6），右 380px AI 对话栏（绑定当前笔记，头部显示"写作助手" + 当前笔记标题）。

- 编辑器与 AI 栏同在一个玻璃面板内，1px 玻璃接缝分隔
- 编辑器高度充满整个面板（覆盖 ByteMD 默认 300px 固定高度）
- AI 修改笔记后：Toast「AI 已修改笔记」＋ 内容刷新（§design.md 9.4）
- 发消息前自动保存（无感），保存失败则提示且不发送

**新建笔记 `/note/new`**：进入即空编辑器，首行聚焦；首次保存才创建记录。

### 4.4 设置页 `/settings`

- 顶栏同首页（搜索框此时弱化）
- 主体单卡（`--glass-1`），分区：
  - **AI 配置**：配置卡列表，每张卡（`--glass-2`）显示：名称 + model + baseUrl（text-2，截断）+「测试连接」按钮；激活卡右上角 teal 圆点 + "使用中" 徽标，其余卡显示「启用」按钮
  - 新增/编辑配置：卡内展开表单或 Modal（名称 / baseUrl / apiKey / model 四字段 + 保存 / 取消）
  - 测试连接：按钮短暂显示 spinner → 结果 Toast「连接成功」/ 错误信息
  - **外观**：深色 / 浅色 / 跟随系统 三选一；「预览正文使用楷体」开关
  - **关于**：版本号（text-3）

## 6. ByteMD 集成与定制

- 依赖：`@bytemd/vue-next` + `@bytemd/plugin-gfm`、`-highlight`、`-mermaid`、`-math`
- 编辑器容器整体套入 GlassPanel；覆盖 ByteMD CSS 变量与 `.bytemd` 类，使工具栏/编辑区/预览区背景透明、跟随 `--glass-*` 层级
- 工具栏按钮：ghost 化（透明底，hover `--glass-2`），激活态 teal 下划线
- `uploadImage` 钩子 → `POST /api/uploads`，粘贴/拖入图片即上传，成功后插入 `![](url)`
- 分屏：默认「编辑 | 预览」双栏；工具按钮切换仅编辑 / 仅预览
- 预览排版定制：
  - 正文：霞鹜文楷 16px / 1.85，text-1；标题层级用字重与间距区分
  - 引用块：左侧 teal 2px 竖线 + `--glass-1` 底
  - 代码块：`rgba(0,0,0,.35)` 底 + JetBrains Mono 13px，右上角复制按钮
  - 表格：细线 `--glass-border`，表头 `--glass-2`
  - 链接：teal + 下划线，hover 提亮

## 7. 动效与交互细节

- **载入编排**（唯一的编排时刻）：顶栏 → 左栏 → 列表 → AI 栏依次浮现，各错开 60ms
- **极光漂移**：三个光斑 60s 周期缓慢位移（transform 大半径旋转），`prefers-reduced-motion` 时静止
- **AI 呼吸**：流式输出时发送按钮变 teal 呼吸点；工具状态行内呼吸点同步
- **快捷键**：`Ctrl+N` 新建笔记，`Ctrl+S` 保存，`Ctrl+K` 聚焦搜索，`Esc` 关闭 Modal/抽屉
- **错误提示**：一律 Toast + 就地文案，说明"发生了什么 + 怎么办"（如"保存失败：网络不可达，修改已保留在编辑器"）
- **空状态文案**：有方向感——首页空列表「写第一篇」；无会话「问我点什么」；无 AI 配置时 AI 栏显示「先在设置中添加 AI 配置」+ 跳转按钮

## 8. 主题切换

- `html[data-theme="dark"|"light"]` + CSS 变量全套切换，组件只引用变量
- 默认深色；选择存 localStorage；`跟随系统` 监听 `prefers-color-scheme`
- ByteMD 预览区高亮主题（highlight 插件）跟随全局主题

## 9. 质量底线

- 键盘可达：所有交互 `focus-visible` 2px teal 环
- 对比度：text-2 与玻璃底对比 ≥ 4.5:1（浅色主题校验）
- `prefers-reduced-motion`：关闭极光漂移与位移动效，保留透明度过渡
- 响应式：桌面优先；< 1180px 时 AI 栏收为悬浮抽屉按钮，< 900px 分类栏同理
